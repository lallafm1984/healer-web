# 출시용 인터랙티브 랜딩 페이지 개편

검토·적용일: 2026-10-31

## 목표와 방향

출시가 임박한 나혼자 힐러의 공식 소개를 더 세련되고 직접 탐색할 수 있는 경험으로 변경했습니다. 기존 성역 일러스트, 청록·금빛 색상, Hahmlet 제목 글꼴, 실제 게임 리소스를 디자인 기준으로 유지했습니다. 별도의 계정, 수집 폼, 영상 서비스, 추적 기능은 추가하지 않았습니다.

## 현재 화면에서 확인한 문제

현재 게시된 사이트를 인앱 브라우저로 열어 캡처한 `qa/redesign/01-before.jpg`를 확인했습니다.

1. **플레이 소개**: 세 개의 스크린샷을 한 번에 보여주는 구성이며 사용자가 관심 장면을 선택해 내용을 탐색하는 흐름이 약했습니다. 사용자가 지적한 개발·버전 차이 안내도 화면에 노출되어 있었습니다.
2. **직업 선택**: 7개 직업 탭과 설명 변경은 작동했지만 직업별 분위기의 변화가 작았습니다.
3. **스크롤 흐름**: 긴 페이지에서 진행 위치를 계속 확인하거나 섹션을 오가기 어려웠고 스크롤에 따른 등장 효과가 없었습니다.

장점은 게임 고유의 그림·색·제목 글꼴, 실제 플레이 화면, 개인정보·지원 페이지의 명확한 구분이었습니다. 이를 개편의 기준으로 사용했습니다. 스크린샷 검토만으로 접근성 준수를 단정하지 않았으며 실제 조작 검사도 별도로 진행했습니다.

## 조사한 공식 자료

- [Hades II / Supergiant Games](https://www.supergiantgames.com/games/hades-ii/): 실제 공식 페이지를 브라우저로 열고 레이어 이미지 중심의 첫 화면, 콘텐츠·플레이 이미지 탐색 구조를 확인했습니다. `reference-hades.jpg`로 캡처했습니다. 게임 고유의 시각 요소를 중심에 두는 접근을 참고했고 그 게임의 이미지나 코드는 복사하지 않았습니다.
- [Genshin Impact 공식 사이트](https://genshin.hoyoverse.com/en-us/home): 공식 페이지의 캐러셀 버튼과 캐릭터·지역으로 이어지는 탐색 구조를 DOM에서 확인했습니다. 이 환경에서는 첫 화면이 로딩 상태에 머물러 전체 시각 디자인을 검증하지 못했으므로 완성 화면의 시각 근거로 사용하지 않았습니다.
- [web.dev: 고성능 CSS 애니메이션](https://web.dev/articles/animations-guide): 위치·크기 재계산을 반복하는 방식보다 transform·opacity 중심으로 동작을 구현했습니다.
- [W3C: Animation from Interactions](https://www.w3.org/WAI/WCAG22/Understanding/animation-from-interactions.html): 비필수 움직임을 끌 수 있도록 수동 토글과 운영체제의 움직임 감소 설정을 지원했습니다. 접근성 전체 적합성 판정을 의미하지는 않습니다.

## 반영 내용

- **첫 화면**: 실제 전투 화면을 배치하고 직업 발견을 주요 행동으로 구성. 포인터 위치·스크롤에 반응하는 성역 배경과 기존 게임의 금빛 효과 이미지 적용.
- **스크롤**: 상단 읽기 진행 표시, 현재 섹션을 표시하는 고정 메뉴, 내용·그림의 순차 등장. 메뉴 이동 시 두 고정 메뉴 아래로 제목이 정렬되도록 처리.
- **모험**: 전투·성장·동료의 세 장면을 이미지 중심의 탐색 카드로 변경. 각 카드는 관련 플레이 장면을 선택하고 해당 섹션으로 이동.
- **직업**: 직업별 배경·문양·강조 색상·설명 전환, 이전·다음 버튼과 위치 표시, 모바일 가로 넘김 및 키보드 방향키/Home/End 지원.
- **플레이**: 전투·장비·길드를 선택하는 갤러리, 이전·다음 탐색, 화면 확대 및 확대 상태의 이전·다음/방향키 탐색.
- **출시 문안**: 개발 빌드·출시 버전 차이·소개 일러스트 안내 제거. 출시 정보는 ‘Google Play · 곧 출시’로 정리. 확인되지 않은 출시 날짜나 다운로드 링크는 만들지 않음.
- **움직임 제어**: ‘움직임 끄기’ 버튼, `prefers-reduced-motion` 반영, 터치 환경의 과한 포인터 효과 제외, 화면 밖·숨겨진 탭에서 장식 애니메이션 정지. 갤러리는 자동 재생하지 않음.

## 코드 및 자산

- `scripts/home.mjs`: 출시용 홈 구성과 직업·갤러리 표현 데이터.
- `dist/interactive.css`: 홈 전용 디자인·반응형 배치·스크롤 등장 효과.
- `dist/experience.js`: 스크롤·포인터 효과, 움직임 제어, 직업·갤러리 탐색.
- `dist/app.js`: 기존 메뉴·대화상자·요청 도구 유지, 직업 선택 알림과 가로 탐색 보완.
- 신규 사용 이미지: 기존 게임의 `scene-school`, `scene-lotusway`, `scene-cathedral`, `scene-oasis`, `fx-title-sunbloom-v1`. 이 개편에서 새로운 이미지를 생성하지 않았습니다.
- `scripts/check.mjs`: 모든 브라우저 스크립트 구문 및 제거 요청 문구가 다시 노출되지 않는지 검사.

## 검증 범위

실제 인앱 브라우저에서 데스크톱·360×780 CSS px 모바일 화면으로 확인했습니다. 단순한 빌드 성공을 화면 검증으로 대체하지 않았습니다.

- 직업 클릭, 이전·다음, End 키 선택 및 문양·배경·카운트 변경 확인.
- 플레이 탭, 이전·다음 순환, 확대 열기·닫기 및 확대 화면 방향키 탐색 확인.
- 스크롤 메뉴 이동과 현재 위치 표시 확인. 모바일 섹션 정렬은 고정 메뉴 121px 아래, 약 135px 위치로 정렬되는 것을 확인.
- 움직임 끄기 선택 시 루트 스크롤 동작이 auto로 바뀌고 등장 효과로 숨겨진 본문이 모두 표시되는 것을 확인.
- 모바일 홈·직업·플레이에서 clientWidth와 scrollWidth 345/345로 가로 넘침 없음.
- 개인정보·지원 문안과 기존 계정 삭제 요청 기능은 유지.

운영체제의 움직임 감소 설정을 실제 기기에서 바꾸는 검사와 실제 Android 기기 검사는 수행하지 않았습니다. 관련 CSS·미디어 질의 처리 코드를 적용하고 웹 브라우저의 수동 모션 끄기를 검증했습니다.
