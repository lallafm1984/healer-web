# Impeccable 상호작용 개선

적용일: 2026-11-02

## 기준

- 작업 시작 기준은 `main`/`origin/main`의 `f2fa1c6`입니다. 작업 트리는 깨끗했으며 원격 변경 사항을 확인했습니다.
- 설치된 Impeccable 4.8.0의 컨텍스트 로더를 실행하고 `polish`, `animate`, Persuade 모드와 `craft-floor` 가이드를 적용했습니다.
- 기존 성역 배경·금빛과 녹색·로컬 글꼴·사제 스크린샷을 유지하는 범위의 개선입니다. 제품 사실, 출시 문구, 개인정보·계정 삭제·지원 내용을 바꾸지 않았습니다.

## 달라진 동작

1. **첫 화면에서 바로 확대**: 대표 사제 이미지는 갤러리로 이동하는 링크 대신 전투 화면을 바로 여는 버튼입니다. 확대 아이콘·안내·키보드 접근을 제공합니다.
2. **모든 모바일 직업을 표시**: 600px 이하에서 직업 탭을 두 줄로 배치했습니다. 가로로 넘기지 않고 모든 직업을 확인·선택할 수 있습니다. 기존 방향키·Home·End 및 이전·다음 기능을 유지했습니다.
3. **이미지를 가리지 않는 갤러리**: 제목·닫기, 스크롤 가능한 게임 화면, 이전·순서·다음 영역을 분리했습니다. 휴대폰의 가로·세로 화면과 데스크톱에서 조작부가 이미지 위에 겹치지 않습니다.
4. **장면 전환과 종료**: 다음 이미지로 바꾸면 이미지의 맨 위부터 보입니다. 닫으면 열었던 버튼으로 포커스가 돌아갑니다. 장면 전환으로 원래 버튼이 숨겨졌다면 현재 갤러리 탭으로 돌아갑니다.
5. **홈 이동**: 같은 페이지의 아래쪽을 살펴보던 중 로고를 누르면 해시를 정리하고 맨 위로 돌아갑니다. 다른 페이지에서의 일반 홈 이동과 새 탭 열기 동작을 유지합니다.
6. **스크롤 안정성**: 모달을 열고 닫을 때 스크롤바 공간을 예약하고, 이미지 영역에는 독립적인 스크롤과 경계 처리를 적용했습니다. 기존 스크롤 연출과 움직임 끄기를 유지했습니다.

## 검증

- Impeccable 정적 검사: 변경한 홈·공통 탐색·아이콘·스타일에서 지적 사항 없음 (`[]`). 자동 훅이나 편집 오버레이는 추가하지 않았습니다.
- 브라우저 확인: 320×780, 360×780, 768×1024, 812×375, 기본 데스크톱 1280×720. 가로 넘침 없이 표시했습니다.
- 360px에서 직업 7개가 모두 화면 안에 표시되고 Home·End 키로 사제↔결계사 전환을 확인했습니다.
- 갤러리의 이미지 스크롤, 다음 장면에서 맨 위로 초기화, Enter 열기, 방향키 전환, Esc 닫기와 포커스 복귀를 확인했습니다.
- 가로 화면 높이 375px에서도 닫기와 이전·다음 버튼이 화면 안에 표시됐습니다.
- 움직임 끄기를 켜면 모션 전환 시간이 0초이며, 홈 이동도 즉시 맨 위로 돌아갑니다.
- `SITE_URL=https://healer.4ltree.com npm run build` 및 `npm run check`가 통과했습니다. 페이지 5개, 내부 참조 215개, 메타데이터·보안 헤더·사이트맵·robots·404를 검사했습니다.
- 개발 브라우저에서 새 경고·오류는 없었습니다. 반응형 브라우저 검증이며 실제 Android 기기 검사나 전체 접근성 인증을 뜻하지 않습니다.

검사 자료는 프로젝트 상위의 `qa/impeccable-20261102-interactions/`에 보관합니다. 후속 선택 사항으로 `$impeccable init`을 실행하면 제품 문맥과 품질 목표를 별도 문서로 정리할 수 있습니다.
