## 발견한 문제와 수정

1. **첫 화면의 읽기 순서**: 작은 영문 소제목이 반복되고 제목보다 위에 장식 라벨이 많았습니다. 홈의 영문 소제목 12개와 불필요한 섹션 번호를 제거하고 제목 → 설명 → 행동 순서로 정리했습니다. 게임 관련 문구와 기능에 관한 사실은 유지했습니다.
2. **모바일에서 게임이 보이지 않음**: 원래 모바일에서는 대표 사제 스크린샷이 `display:none`이었습니다. 2열 소형 배치로 변경해 첫 화면 안에서 실제 게임과 주요 행동을 함께 볼 수 있게 했습니다.
3. **작은 본문과 조작 영역**: 모바일 소개 본문은 12px, 움직임 버튼은 높이 32px이었습니다. 홈 본문은 16px 중심, 주요 탐색은 14px, 부가 정보는 12px로 구분하고 동작 버튼은 최소 44px로 맞췄습니다.
4. **반복적인 같은 크기의 카드**: 모험 소개는 전투 장면을 크게, 성장·동료 장면을 보조 크기로 배치했습니다. 모바일에서는 내용 순서대로 한 열로 이어집니다.
5. **직업 설명의 긴 모바일 배치**: 직업 이름과 문양을 나란히 놓고 설명은 전체 너비를 사용하도록 했습니다. 텍스트를 줄이지 않고 읽을 공간을 확보했습니다.
6. **과한 장식·균일한 등장 효과**: 무한 반복 장식과 모든 본문을 숨기는 방식을 걷어내고, 이미 읽을 수 있는 기본 상태에서 성역 배경 이동과 모험 이미지의 짧은 공개 효과에 움직임을 집중했습니다. 수동·시스템 모션 감소, 직업 전환, 갤러리 확대는 유지했습니다.
7. **브라우저 기본 표현**: 포커스, 선택, 스크롤바, 탭의 선택 상태와 숫자 표시를 게임 색상·역할에 맞췄습니다. 푸터 장식 문자는 실제 앱 아이콘으로 바꿨습니다.

## 확인 범위

- Impeccable 소스 검사: 수정한 홈 컴포넌트·공통 탐색·홈 스타일에서 지적 사항 없음 (`[]`).
- 실제 인앱 브라우저에서 모바일 직업 선택, End 키, 갤러리 확대·다음 이미지·Esc 닫기를 확인했습니다.
- 모바일 직업 설명은 16px, 이전·다음 버튼은 44px, 문서 너비/스크롤 너비는 345/345px로 확인했습니다.
- 320×780, 360×780, 768×1024 및 기본 데스크톱 화면에서 가로 넘침 없이 표시했습니다. 모바일 첫 화면에도 사제 전투 화면이 보입니다.
- 데스크톱의 직업 링크는 고정 탐색 아래로 이동하고 현재 섹션 표시·읽기 진행 표시·성역 배경 이동이 작동했습니다.
- `SITE_URL=https://healer.4ltree.com npm run build`가 통과했습니다. `npm run check`로 5개 페이지, 내부 참조 216개, SEO 메타데이터, 보안 헤더, 사이트맵·robots·404 검사가 통과했습니다.
- Next.js의 권고에 따라 루트에 `data-scroll-behavior="smooth"`를 추가했습니다. 기존 언어 검사는 `<html lang="ko">` 전체 문자열에 의존하므로 추가 속성이 있어도 실제 한국어 속성을 확인하도록 수정했습니다. 출시 빌드에서 지원 페이지 이동·홈 복귀 후 새 브라우저 경고나 오류가 없었습니다.
- 사제 전투 스크린샷, 개인정보·삭제·지원 경로, Google Play ‘곧 출시’ 상태와 배포 방식은 유지했습니다.
- 설치는 스킬 파일 방식입니다. 자동 훅을 새로 등록하거나 브라우저에 Impeccable 편집 오버레이를 주입하지 않았습니다.
