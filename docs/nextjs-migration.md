# Next.js 전환 및 검증

검증일: 2026-10-31 (한국 시간)

- Next.js 16.4.3 / React 19.3.1 App Router로 전환. Node.js 24 LTS로 실행 버전 고정.
- 홈, 개인정보처리방침, 이용약관, 삭제 요청, 고객지원 및 사용자 정의 404를 React 페이지로 구성.
- 기존 이미지·폰트·스타일을 유지하고 정적 생성기·OpenAI Sites 설정을 제거.
- 직업·갤러리 선택, 키보드 탐색, 대화상자와 삭제 요청 작성은 React 상태로 처리.
- 스크롤·모션 관련 리스너, 프레임 요청과 관찰자는 페이지 이동 때 정리.
- 사이트맵·robots·페이지별 메타데이터, 보안 헤더와 Vercel 자동 인식 설정 추가.
- 웹사이트 호스팅 안내는 Vercel로 변경.

## 검증 결과

- `npm run build`: 모든 페이지의 사전 렌더링 성공.
- `npm run check`: 5개 정상 페이지, 211개 내부 참조, 검색·공유 메타데이터, 보안 헤더, 사이트맵·robots 및 404 검사 통과.
- 의존성 설치 시 npm 보안 검사: 취약점 0개.
- 실제 Chrome: 1440×1000 데스크톱 및 360×780 모바일 화면 확인.
- 모바일 문서 가로 너비 / 스크롤 너비: 345 / 345px (360px 뷰포트의 스크롤바 제외), 가로 넘침 없음.
- 드루이드 선택, End 키로 결계사 이동, 다음 버튼으로 사제 순환 확인.
- 장비 화면 확대, 다음 확대 화면으로 길드 이동, Esc 닫기 확인.
- 모바일 메뉴에서 고객지원 이동, 메뉴 닫힘 및 FAQ 펼침 확인.
- 가상 예시로 삭제 요청문 갱신과 클립보드 복사 확인. 메일 발송·삭제 요청 전송은 수행하지 않음.
- 고객지원 → 삭제 요청 → 홈 이동 후 기능 초기화 및 콘솔 오류·경고 없음.

실제 기기 검증은 수행하지 않았습니다. Vercel 배포 결과는 해당 프로젝트의 배포 화면과 공개 주소에서 별도로 확인합니다.
