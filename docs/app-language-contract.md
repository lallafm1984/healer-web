# 앱과 웹의 언어 전달

적용일: 2026-11-02. 웹 작업 시작 기준: `6c95ad2` (`main`/`origin/main` 일치).

## URL과 우선순위

- 기존 경로는 유지합니다: `/privacy/`, `/terms/`, `/delete-account/`, `/support/`, `/`.
- 앱은 `https://healer.4ltree.com/privacy/?lang=ja` 형식으로 `lang=ko|en|ja`를 전달합니다.
- 우선순위: 유효한 `lang` → 저장된 웹 언어 쿠키 → 브라우저의 첫 번째 언어.
- 브라우저 언어는 `ko`, `ko-KR` 또는 `ja`, `ja-JP`이면 해당 언어이며 나머지와 누락은 영어입니다. `kok-IN`을 한국어로 해석하지 않습니다. 지원하지 않는 쿼리·쿠키 값은 무시합니다.
- URL 언어와 저장된 웹 언어가 다르면 URL 언어로 표시하고 저장 선택도 갱신합니다. 저장이 차단되어도 URL과 내부 링크의 언어 전달은 동작합니다.

## 구현

Next.js Proxy가 언어를 검증하고 요청 헤더로 전달합니다. 외부에서 같은 이름의 헤더를 보내도 덮어씁니다. 루트와 페이지는 서버에서 같은 요청 언어를 읽으므로 초기 HTML의 `lang`, 제목, 본문과 `Content-Language`가 일치합니다. 따라서 본문이 열린 뒤 한국어에서 다른 언어로 전환되는 방식을 사용하지 않습니다.

웹 페이지는 이제 요청 시 렌더링됩니다. 정적 `dist` 출력 방식으로 배포하지 않습니다. 기존 Vercel Next.js 배포 구성을 그대로 사용합니다. robots와 사이트맵은 정적입니다.

공통 메뉴·푸터·문서 내 링크는 `lang`을 유지합니다. 언어 선택 링크는 일반 `<a>`로 전체 문서를 새로 탐색해 루트 레이아웃·메타데이터·클라이언트 문맥까지 함께 갱신합니다. 이 링크만 Next Link로 바꾸면 루트 레이아웃이 이전 언어로 재사용될 수 있으므로 주의합니다.

언어 선택에는 `healer-web.lang` 기능성 쿠키만 사용합니다. 값은 `ko`, `en`, `ja` 중 하나이며, 최대 180일·SameSite=Lax·HttpOnly·HTTPS에서 Secure로 설정합니다. 이 기능을 개인정보처리방침에 설명하고 시행·최종 수정일을 2026-11-02로 갱신했습니다. 삭제 작성 내용은 여전히 브라우저 메모리에만 있으며 전송·저장하지 않습니다.

개인정보 9개·약관 6개 절의 항목, 데이터 종류, 60일·30일 보관 설명, Google 계정 자체의 비삭제 및 로컬 데이터 별도 삭제 안내를 번역에 유지했습니다. 삭제 안내·요청 도우미·복사 결과·이메일 제목과 본문·FAQ·홈의 직업과 갤러리·공통 메뉴·404를 번역했습니다.

한국어 캡처는 기존 파일을 사용합니다. 영어·일본어 캡처는 게임 프로젝트의 `나혼자힐러/리소스/스토어-다국어-20261031-v1/원본/S25/{en-US,ja-JP}/`에서 `01-priest-party.png`, `08-equipment.png`, `07-guild-members.png`를 가져왔습니다. 내용을 덧씌우지 않고 540×1170 JPEG로 축소·압축했습니다. 사제 전투 장면을 유지하며 언어별 장면의 적 이름이 다르므로 대체 텍스트는 특정 보스 이름에 의존하지 않습니다.
